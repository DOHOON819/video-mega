# Video Mega

Video Mega is a local-first AI video studio. Its browser interface connects to the Video Mega engine running on your own PC, then uses Ollama for story planning and LTX-2.5 for HD video with native audio.

Open the web interface at **https://dohoon819.github.io/video-mega/** after starting the local Video Mega engine.

- Select a reference image to keep the protagonist consistent.
- Continue compatible shots from the preceding clip's final frame.
- Plan long stories in ordered scenes and assemble them into one MP4.
- Run locally without paid generation credits.

The public Pages build contains only the browser interface. Models, reference images, projects, generated videos, and the local connection key stay on the user's computer.
